# Abdullah Kabeer | Personal Portfolio

A premium, editorial-style personal portfolio showcasing the intersection of hardware innovation and quantitative engineering. Built with a focus on rich aesthetics, smooth animations, and a sophisticated typographic layout.

Live at: [abdullahkabeer.com](https://abdullahkabeer.com)

## 🎨 Design Philosophy

- **Editorial Aesthetic**: High-contrast serif typography paired with clean, architectural layouts.
- **Interactive Depth**: Smooth transitions and scroll-triggered animations using Framer Motion.
- **Glassmorphism**: Subtle background blurs and depth layers for a modern, premium feel.
- **Responsive Excellence**: Fully optimized for mobile, tablet, and desktop viewports.

## 🛠 Tech Stack

- **Framework**: [React](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Playfair Display (Serif) & Inter (Sans)

## 📁 Key Sections

- **Works**: Featured projects including Altruato, UVSET, and Quantitative Trading Infrastructure.
- **Patents**: Detailed breakdown of three US Patents across driver safety and environmental control.
- **Experience**: Timeline of work history and research scholarships (CCIR).
- **Education**: Academic background at The University of Texas at Austin.
- **Honors**: Global recognitions and innovation awards.

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/AbdullahKabeer/PersonalSite.git

# Install dependencies
npm install
```

### Development

```bash
# Start the development server
npm run dev
```

### Production

```bash
# Build for production
npm run build
```
